Om meg

Praktisk erfaring møter teknologi

Jeg heter Margeir Oddgeirsson og studerer IT-drift. Fra før har jeg fagbrev som anleggsmaskinmekaniker, og den praktiske måten å løse problemer på tar jeg med meg inn i IT-faget.

Profil

Jeg liker å forstå hvordan ting fungerer, enten det handler om maskiner, systemer eller kode. I skolearbeidet mitt jobber jeg med nettsider, enkel programmering, dokumentasjon og IT-drift.

Målet mitt er å bygge en portefølje som viser både teknisk forståelse, strukturert arbeid og evnen til å lage løsninger som er enkle å bruke.

Ferdigheter

  • HTML, CSS og grunnleggende JavaScript
  • IT-drift, feilsøking og systemforståelse
  • Planlegging og gjennomføring av skoleprosjekter
  • Dokumentasjon og samarbeid

Interesser

Jeg liker discgolf og kreative prosjekter, spesielt når teknisk funksjon og visuell presentasjon møtes.

Videre mål

Jeg vil utvikle flere prosjekter, bli tryggere på front-end og bygge videre kompetanse innen IT-drift og brukerstøtte.
